01Then · You read the page

One door, built for eyes.

  • A website is a menu, a cookie banner and a sign-up form. It was built for a person looking at a screen.
  • An agent gets the same page as tag soup: wrappers, scripts and navigation, with the content somewhere inside.
  • The same link can open two doors. A browser gets the page. An agent that asks for Markdown gets the text.

02Now · Your agent reads the docs

Agents come in through the docs.

  • Today's agent customers are builders' agents. They read docs and llms.txt files before they read a homepage.
  • For agents, the format changes the result. A person does not care whether text sits in a PDF, a doc or a PNG. An agent does.
  • Powerful models can use your website. That doesn't mean they should. A screen agent takes many steps to do what an API does in a few calls.
  • A command line takes flags, not forms. Give the agent a door it can walk through, and keep the screen for the moment a person decides.

04Leave knowing

The checklist.

For the agent

What the agent should get

  1. Discover. A Markdown page at the same address, an llms.txt, a skill file. Link: </llms.txt>; rel="alternate"
  2. Price. The price in the reply, not behind a form. HTTP 402 + payment terms
  3. Permission. A request the human can say yes to, and a way to wait for the answer. approve link · wait
  4. Pay. A receipt it can show: what, how much, to whom. receipt · transaction
  5. A CLI that takes flags, not forms. JSON on request, exit codes that mean something, read-only until told to act.
For the person

What the human should see

  1. A picture of what is being bought.
  2. The total in one line, with the currency.
  3. What it matches from the request, point by point, with any difference flagged quietly.
  4. Two alternatives side by side. Side by side, people choose differently. Agents pick the first offer 60 to 100% of the time in a simulated market. Show the options, not only the pick.
  5. How to undo it.
  6. What this yes covers: this order only, for a limited time.
For both

Where trust is earned

  1. Before: the mission and its fence. Budget, limits, an end date.
  2. During: a yes, only where you want one. Record who said it, the person or the agent.
  3. After: the receipt, and a ruling in plain words if it goes wrong. Under Visa's rules the cardholder answers for the agent's purchase "as if the Cardholder initiated" it.
  4. Recourse at the speed agents trade. 88 real consumer disputes replayed with AI jurors:
    People 48.9 h
    AI 9.8 min
    72 of 88 rulings the same · drawn to scale

At full autonomy the middle crossing fades. The other two never do. People stay as the expensive exit, on appeal (being built).
